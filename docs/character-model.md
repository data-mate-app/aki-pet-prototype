# キャラデータの設計（作り直し版）

ChatGPT「秋プロ」で整理したキャラデータを、このプロトタイプ用に作り直した。正本は `src/domain/pet.ts`・`src/data/species.ts`・`src/domain/life.ts`。

## 方針

1. **3 層に分ける**
   - 種族の定義（変わらない）: `SpeciesDef`
   - 育成の保存データ（変わる）: `PetSave`
   - いまの調子（毎回計算する。保存しない）: `Condition`
   調子を保存すると、生活の記録と食い違うため。
2. **アニメーションは組み合わせで表す**。20 種類を個別に持たず、`姿勢 Pose × 表情 Expression × 一回の動作 Action × 調子による変調 Modulation` で描き分ける。たとえば同じ「歩く」でも、元気・疲れ・眠いで速さ・跳ね・耳の垂れ・目の開きが変わる。
3. **罰を与えない**。数値には下限があり、病気・死亡・家出の状態を持たない。データが足りないときは推測せず `null`（不明）にする。

## 種族（3 種）

| id | 名前 | 動物 | 性格 | 動きの個性（motion） |
|---|---|---|---|---|
| komugi | こむぎ | いぬ | 元気 | 速く歩き、よく跳ねる |
| omochi | おもち | くま | のんびり | ゆっくり、呼吸が深い |
| potato | ぽてと | ねこ | 好奇心 | よく歩き回る |

`motion`（歩く速さ・跳ね・呼吸・まばたき間隔・歩き回る頻度）は種族の個性で、調子による変調はこれに掛け合わせる。

## 保存データ `PetSave`

| 項目 | 意味 |
|---|---|
| vitals.energy | 元気。睡眠記録から決まる。睡眠記録がなければ `null`（不明） |
| vitals.fullness | おなか。食事で増え、起きている間に時間で減る |
| vitals.smarts | かしこさ。その日のタスク・集中で増える |
| growth.focus / planning / rhythm | 集中力・計画力・生活リズム。日をまたいで少しずつ伸びる |
| level / xp | 次のレベルまで `20 + (level - 1) × 12` XP |
| bond | 親密度 0〜100（なでると増える） |
| asleepSince | 寝かせた時刻。起きている間は `null` |

下限 `VITAL_FLOOR`: 元気 15・おなか 10。これ以上は下がらない。

## 調子 `Condition`

優先順: 眠っている → 疲れ → おなか → 眠気（深夜）→ 退屈 → ご機嫌 → おだやか。
`reason` は吹き出しの文例を選ぶキーで、責める言い方はしない。

| 調子 | 速さ | 跳ね | 耳の垂れ | 目の開き | 待機の表情 |
|---|---|---|---|---|---|
| happy | 1.15 | 1.3 | 0 | 1 | happy |
| calm | 1 | 1 | 0.1 | 1 | neutral |
| sleepy | 0.7 | 0.5 | 0.5 | 0.55 | sleepy |
| hungry | 0.85 | 0.7 | 0.35 | 0.9 | bored |
| tired | 0.6 | 0.4 | 0.7 | 0.7 | tired |
| bored | 0.9 | 0.8 | 0.25 | 0.85 | bored |
| asleep | 0 | 0 | 0.6 | 0 | sleepy |

## 生活の記録と報酬

記録 `LifeEvent` の種類: checkin / meal / focus / task / reflection / interaction / sleep。
報酬は 1 日の上限つき。同じ記録（eventId）は二重に数えない。集中は 20 分以上で報酬。

| 記録 | XP | コイン | 親密度 | 1 日の上限 |
|---|---|---|---|---|
| 朝のチェックイン | 5 | 2 | 0 | 1 |
| ごはん | 3 | 1 | 0 | 3 |
| しゅうちゅう | 10 | 4 | 0 | 3 |
| タスク完了 | 6 | 2 | 0 | 3 |
| 夜のふりかえり | 5 | 2 | 0 | 1 |
| なでなで | 0 | 0 | 2 | 5 |
| すいみん | 0 | 0 | 0 | 1（元気を決めるだけ） |

睡眠時間から起きたときの元気: `40 + (時間 - 4) × 16`（30〜100 に収める）。
