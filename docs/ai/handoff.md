## 確かめたこと（ブラウザ、スマホ幅 375×812 と PC 幅 1440×900）

- 初回の流れ、部屋の表示（朝・夜）、床タップで歩く、ペットをタップ（わっ）・なでる（ハート 4 つ → うれしい！）
- 家具タップの吹き出し、ベッドで寝かせる → 起こす → 時計を回す → 睡眠を記録（Island 通知・コインが飛ぶ）
- もようがえ: 家具を箱へしまう、箱から出す（タップで空いている場所へ）、別の場所へ運ぶ、できた
- 集中: 目盛り、タイマー（デモ早送り ×60）、終了カードと Island 通知
- きろく: きょう・1 週間（不明の日の表示）
- おみせ: 詳細、長押しで買う（コインが減る）、部屋に置く → もようがえで空いている場所へ自動で置かれる
- PC 幅のデモ操作（時刻を夜へ早送り → 部屋の光が変わる）
- コンソール: 再読み込み後にエラーなし（合成イベントによる `navigator.vibrate` のブラウザ警告のみ）

## 確認中に直したこと

- 端末の枠が 102px スクロールしてずれる → `.device` と `.app` に `overflow: clip`
- 起きたあと部屋が暗いまま → 時計を回した直後に起こす（睡眠の記録はそのあと）
- おみせの「部屋に置く」で家具が置かれない → 依頼を消したときにタイマーまで消していた
- おみせの詳細がタブバーの下に隠れる → 開いている間はタブバーを下げる
- 集中の目盛りの端に白い箱が出る → 背景色で塗る代わりに mask で透かす
- 集中中（暗い画面）にステータスバーの文字が見えない → 白にする
- おみせタブの塗りアイコンが王冠に見える → 取っ手も同じ色に
