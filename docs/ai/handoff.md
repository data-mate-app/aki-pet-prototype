## 確かめたこと（ブラウザ、スマホ幅 375×812 と PC 幅 1440×900）

- 初回の流れ、部屋の表示（朝・夜）、床タップで歩く、ペットをタップ（わっ）・なでる（ハート 4 つ → うれしい！）
- 家具タップの吹き出し、ベッドで寝かせる → 起こす → 時計を回す → 睡眠を記録（Island 通知・コインが飛ぶ）
- もようがえ: 家具を箱へしまう、箱から出す（タップで空いている場所へ）、別の場所へ運ぶ、できた
- 集中: 目盛り、タイマー（デモ早送り ×60）、終了カードと Island 通知
- きろく: きょう・1 週間（不明の日の表示）
- おみせ: 詳細、長押しで買う（コインが減る）、部屋に置く → もようがえで空いている場所へ自動で置かれる
- PC 幅のデモ操作（時刻を夜へ早送り → 部屋の光が変わる）
- コンソール: 再読み込み後にエラーなし（合成イベントによる `navigator.vibrate` のブラウザ警告のみ）

## 音を付けた（2026-11-20）

- 素材はローカルの Stable Audio 3 で生成し、数値（長さ・音の塊の数・明るさ・テンポ）で選んで加工した。一覧・作り方・差し替え方は [docs/sound.md](../sound.md)。
- ブラウザ（スマホ幅 375×812 と PC 幅）で、出力に AnalyserNode をつないで音量を測って確かめた:
  - 最初のタップで AudioContext が動き、効果音 12 ファイルと今の時間帯の曲を読み込む（夜 21:54 → `bgm_night`）
  - 右上の音ボタンで消す → 出力 0、戻す → 再開
  - デモ操作で時刻を昼へ → `bgm_day` に切り替わる
  - 集中を始める → 部屋の曲が止まり雨音、環境音ボタンで消す → 出力 0、集中を終える → 部屋の曲に戻る
  - デモ操作の「音を聞く」→ コイン 5 枚が BGM の上で鳴る（ピーク 0.139、BGM 0.037）
- 触られる前に `navigator.vibrate` を呼んでコンソールに出ていたエラーは、`navigator.userActivation` を見て呼ばないようにした。

## 確認中に直したこと

- 端末の枠が 102px スクロールしてずれる → `.device` と `.app` に `overflow: clip`
- 起きたあと部屋が暗いまま → 時計を回した直後に起こす（睡眠の記録はそのあと）
- おみせの「部屋に置く」で家具が置かれない → 依頼を消したときにタイマーまで消していた
- おみせの詳細がタブバーの下に隠れる → 開いている間はタブバーを下げる
- 集中の目盛りの端に白い箱が出る → 背景色で塗る代わりに mask で透かす
- 集中中（暗い画面）にステータスバーの文字が見えない → 白にする
- おみせタブの塗りアイコンが王冠に見える → 取っ手も同じ色に

## 未実施・残る問題

- **独立レビュー（Fable 5.1）は未実施**。
- 実機（iOS Safari / Android Chrome）では未確認。iOS Safari は `navigator.vibrate` を持たないので触覚は出ない（効果音のみ）。
- **音は耳で確かめていない**（担当が聞けないため数値で選んだ）。音量の釣り合い・好みは本人に聞いて直す。
- iOS はマナーモード（消音スイッチ）のとき Web の音が鳴らない。ブラウザの仕様どおりで、変えていない。
- 本番ビルドの JS が 558 kB（gzip 186 kB）で Vite の 500 kB 警告が出る。プロトタイプなので分割していない。
- HMR 中に一度だけ React の重複 key 警告（key `1`）が出た。再読み込み後は再現しない。`ui/fx.ts`・`ui/Island.tsx` のモジュール内連番が HMR でリセットされたためと推定（未確定）。
- なでる判定は指の移動 90px 以上。マウスの短いドラッグでは反応しない。
