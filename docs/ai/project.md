# 案件情報: DataMate プロトタイプ（秋プロジェクト）

## 目的

ChatGPT プロジェクト「秋プロ」で構想したペット育成アプリ DataMate の、操作感と演出を確かめるためのモック。

- 生活の記録（睡眠・食事・集中・タスク・ふりかえり）で、ペットの調子・レベルと部屋が育つ。
- 記録がない日は「不明」のまま扱い、責めない。罰（病気・死亡・家出）は持たない。
- このプロトタイプで最も重視するのは **UI コンポーネントとアニメーション**。ネイティブアプリの良い操作感（バネの動き、指に付いてくるドラッグ、触覚、途切れない遷移）を Web で再現する。

## 完成条件（このプロトタイプ）

- [x] 初回の流れ（種族を選ぶ → 名前を付ける → 部屋へ）
- [x] へや: 等角投影の部屋、時刻に合わせて連続して変わる光、ペットの歩行・待機・調子による動きの違い
- [x] へや: 床タップで歩く、ペットをタップ・なでる、家具ごとの使い方（ねる・すわる・ごはん・集中・きろく）
- [x] もようがえ: 長押しで持ち上げ、置き場所へ吸い付く、下の箱へしまう、箱から出す、もとにもどす
- [x] 睡眠: 寝かせる → 起こす → 時計を回して起きた時刻を決める → 記録
- [x] 集中タイマー（目盛り）、きろく（きょう／1週間）、おみせ（長押しで買う → 部屋に置く）
- [x] レベルアップ、報酬のコインが HUD へ飛ぶ演出、Dynamic Island 風の通知
- [x] デモ操作（時刻の早送り、状態の切り替え、データ消去）
- [ ] 独立レビュー（Fable 5.1）
- [ ] 実機（iOS Safari / Android Chrome）での触り心地の確認

## 範囲外

## 技術と検証

- React 19 / TypeScript 5.9 strict / Vite 8 / motion 14（`motion/react`）/ zustand 5（persist キー `datamate-proto-v1`）/ vitest
- `pnpm verify` = `tsc -b && vitest run && vite build`
- 開発サーバー: `pnpm dev`（port 5320, host 公開）

## 重なり順（z-index）

`.device` が `isolation: isolate` なので、すべて端末の枠の中で重なる。

| 層 | z-index |
|---|---|
| 画面（screen-swap） | なし |
| おみせの詳細 | 40（開いている間はタブバーを下げる） |
| タブバー | 50 |
| BottomSheet | 60 |
| もようがえでドラッグ中の部屋 | 70 |
| ステータスバー | 100 |
| 初回の流れ | 120 |
| レベルアップ | 140 |
| 演出（コイン・ハート） | 150 |
| Island 通知 | 200 |

部屋の中: 家具は `1000 + 奥行き × 100`、置き場所の印 950、波紋 960、ドラッグ中 4000。
